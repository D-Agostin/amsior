# Contribuições

O Amsior é software livre (AGPL-3.0), mas **não aceita contribuições externas
por enquanto**. O projeto ainda está fechando a arquitetura e o método de
verificação, e cada passo exibido precisa passar por revisão do autor.

- *Pull requests* não são aceitos e serão fechados sem análise.
- Relatos de erro são bem-vindos: abra uma *issue* descrevendo a equação
  digitada, a variável isolada e o que apareceu de errado.
- Você pode usar, estudar, copiar e modificar o código nos termos da
  [licença](LICENSE).

Quando o projeto abrir para contribuições, este arquivo será atualizado com
as regras.
